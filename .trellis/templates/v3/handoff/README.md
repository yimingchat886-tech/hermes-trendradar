# Trellis Harness

This repository is the standalone mother repo for the v3 Trellis harness. It
keeps reusable workflow assets, templates, specs, hooks, and handoff documents
separate from downstream product code.

## Start Here

- `AGENTS.md` is the portable AI project-context entry point. Do not edit inside
  its `TRELLIS:START` managed block.
- `.trellis/workflow.md` is the source of truth for Trellis phases, routing, and
  active-task behavior.
- `.trellis/spec/` stores stable project rules for parent/child work, protocol
  phrases, commit/archive boundaries, and distribution policy.
- `HANDOFF.md` is the top-level downstream handoff index.
- `docs/runbooks/hermes-skill-invocation.md` documents the Hermes handoff
  package contract.

## Supported Surfaces

v3 first-class platform assets are Codex and Claude Code. Other historical
adapter references are legacy compatibility notes unless a local spec says
otherwise.

## Handoff Policy

Handoff docs link to `.trellis/workflow.md` instead of copying workflow blocks.
The optional `.hermes.md` file is not generated by default; add it only for a
downstream repo that expects Hermes Agent to read repo-local context directly.

No live Hermes invocation, downstream overlay apply, push, or npm package
dependency is part of this harness handoff.
